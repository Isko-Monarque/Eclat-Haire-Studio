Éclat Hair Studio

Site vitrine professionnel créé pour un salon de coiffure fictif situé à Abidjan.

Objectif

Cette réalisation sert de démonstration pour présenter un modèle de site vitrine destiné aux entreprises, commerces et professionnels souhaitant développer leur présence en ligne.

Le site permet notamment de :

- présenter l'activité ;
- présenter les services et tarifs ;
- afficher une galerie photos ;
- présenter les informations de contact ;
- faciliter le contact via WhatsApp ;
- proposer une expérience adaptée aux téléphones, tablettes et ordinateurs.

Technologies

- HTML5
- CSS3

Responsive

Le site est conçu pour s'adapter aux différentes tailles d'écran :

-  Mobile
- Tablette
- Ordinateur

¶ Statut

Projet de démonstration — non affilié à un véritable salon de coiffure.

Réalisation

Projet réalisé dans le cadre de la création de sites vitrines professionnels pour entreprises, commerces, indépendants et professionnels.
